# Stage 2 editorial policy

- Replace only the explicitly scoped red first-name decisions unless the user expressly authorizes undecided names for a named clothing trait.
- Preserve surnames, surname sources, notes, and every unrelated decision.
- Prefer one given name from the cited inspiration. Use one family name only when the given name is already used or distinctly less collectible.
- Never concatenate a person's given and family names into a synthetic first name.
- For business-themed batches, avoid living public figures and modern celebrity-brand names. Prefer ordinary given names from deceased historical founders or clearly generic fictional directions. This is an editorial-risk reduction rule, not legal advice.
- Famous-animal and athlete batches use a single pet, character, given, or family name with explicit source provenance.
- Every proposal must be globally unique across the effective 3,333-character live state before it is applied.
