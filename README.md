# Panic Name Studio

Shared cross-device curation for the 3,333 Panic Survivors names.

The production app uses:

- Vercel static hosting and serverless API routes
- an Upstash Redis resource connected through the Vercel Marketplace
- a team passcode stored only in Vercel environment variables
- the closed artist Japanese CSV-derived catalog
- curated clothing-theme Western first-name banks
- reviewed source-trait surname fragment banks

The August 2 curation export is the initial authoritative cloud seed:
124 touched characters, 181 approved parts, and 27 replacement requests.

No secrets, source spreadsheets, or original 1080px GIFs are committed here.
The included 640px WebP portraits are lossless review copies; all source GIFs
had two identical frames.
